# Student Placement Eligibility Prediction Using Logistic Regression

## 1. Introduction

Student placement eligibility is an important classification problem in an educational environment. Students can differ in academic performance, attendance, coding ability, project experience, internship experience and number of backlogs.

The objective of this project is to develop a machine learning model that predicts whether a student is likely to meet a placement eligibility criterion.

Logistic Regression was selected because the problem is a binary classification task and the model also provides interpretable coefficients.

## 2. Problem Statement

The objective is to predict the placement eligibility status of a student using six input variables:

* CGPA
* Attendance percentage
* Coding score
* Projects completed
* Internship months
* Backlogs

The target variable is binary:

* 1 represents the positive/eligible class.
* 0 represents the negative/not-eligible class.

## 3. Dataset

The dataset contains 1,000 records and six predictor variables together with the binary target variable.

The dataset variables are:

| Variable           | Description                     |
| ------------------ | ------------------------------- |
| cgpa               | Student CGPA                    |
| attendance_pct     | Attendance percentage           |
| coding_score       | Coding performance score        |
| projects_completed | Number of completed projects    |
| internship_months  | Internship experience in months |
| backlogs           | Number of backlogs              |
| target             | Placement eligibility target    |

## 4. Data Preprocessing

The dataset was first inspected for missing values, duplicate records, data types and class distribution.

Missing numerical values, if present, were handled using median imputation.

Feature scaling was performed using StandardScaler because the input variables have different numerical ranges.

The dataset was divided into training and testing sets using an 80:20 split. Stratified splitting was used to preserve the class distribution.

Preprocessing was implemented inside a Scikit-learn Pipeline to avoid data leakage between the training and testing datasets.

## 5. Model

Logistic Regression was used as the classification algorithm.

The model configuration was:

* Algorithm: Logistic Regression
* Maximum iterations: 1000
* Random state: 42
* Test size: 20%
* Feature scaling: StandardScaler
* Missing-value handling: Median imputation

## 7. Confusion Matrix

The confusion matrix was used to understand the classification errors.

The four outcomes are:

* True Positive: Student correctly predicted as eligible.
* True Negative: Student correctly predicted as not eligible.
* False Positive: Student predicted as eligible but actually not eligible.
* False Negative: Student predicted as not eligible but actually eligible.

The generated confusion matrix provides a more detailed view of the model's classification performance than accuracy alone.

## 8. Coefficient Interpretation

Logistic Regression coefficients were analyzed to understand how the input variables influence the predicted positive class.

A positive coefficient indicates that an increase in the corresponding feature is associated with an increase in the model's predicted probability of the positive class, while a negative coefficient indicates the opposite direction.

The actual coefficient values were obtained from the trained model and saved in `coefficient_analysis.csv`.

The coefficient analysis should be interpreted using the actual model output rather than assuming a feature's effect before training.

## 9. Limitations

This project has several limitations.

First, the dataset is intended for educational practice, so its results should not be treated as a real-world placement decision system.

Second, Logistic Regression assumes a relatively simple relationship between the predictors and the log-odds of the outcome.

Third, the model's performance depends on the quality and representativeness of the provided dataset.

Finally, a real placement system would require additional factors, validation on real-world data and careful consideration of fairness and decision-making risks.

## 10. Possible Improvements

Future improvements could include:

1. Hyperparameter tuning.
2. Cross-validation.
3. Threshold optimization.
4. Comparison with tree-based classification models where technically justified.
5. Additional relevant student features.
6. Evaluation on an independent real-world dataset.
7. Fairness and bias analysis.

## 11. Conclusion

This project developed a complete binary classification workflow for predicting student placement eligibility using Logistic Regression.

The workflow included dataset inspection, data-quality checks, preprocessing, train-test splitting, model training, performance evaluation, confusion-matrix analysis and coefficient interpretation.

The final model provides an interpretable baseline for the student placement eligibility problem. Its practical usefulness should be assessed using the actual evaluation results and, for real applications, validated using representative real-world data.
